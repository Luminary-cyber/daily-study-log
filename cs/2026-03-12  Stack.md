제공하는 연산 중에서 삽입과 삭제가 있는데 삽입은 push, 삭제는 pop으로 정의한다.
리스트는 세우면 스택하고 동일하다. 그래서 리스트를 스택으로 곧바로 쓸 수 있지만 리스트를 쓰다가 실수로 다른 함수를 이용해서 스택에 들어있는 값을 참고하거나 변경할 수 있기 때문에 스택을 만들어 함수 2개만 사용하여 쓴다
```python
class Stack:
    def __init__(self):
        self.items = []
    def push(self, val):
        self.items.append (val)
    def pop(self):
        try:
            return self.items.pop()
        except IndexError:
            print("Stack is empty")
    def top(self):
       try:
           return self. items[-1]
       except IndexError:
           print("Stack is empty")
    def __len__(self):
        return len(self.items)
```
