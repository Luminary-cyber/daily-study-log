


Big-O표기법이란 함수값(수행시간)을 결정하는 최고차항만으로 간단하게 표기 하는 것이다


예를 들어 T1(n)=2n-1 T2(n)=4n+1 T3(n)=3/2n³ + 3/2n +1에서 이것들을T1(n)=O(n) T2(n)=O(n) T3(n)=O(n³)로 표기한다

순서로 나타내면 
1. 최고차항만 남긴다
2. 최고차항 계수는 생략
3. Big-O(최고차항)
이다


코드로 표현해서하면

**비트 수 세는 코드** 
def numebr_of_bits(n):
    count=0
    while n > 0:
        n= n//3
        count+=1
    return count
여기서 n은 갈수록 n/2, n/4, ...... ,n/2** count
이다

그러므로 n/2 ** count, n= 2 ** count, log2n=count
**T(n)= O(log2n)** 이다
