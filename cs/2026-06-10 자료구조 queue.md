
큐(queue):FIFO(First-in First-out)규칙의 순차적자료구조

insert(삽입)  -->enqueue 
delete(삭제) -->dequeue


queue에서 값이 추가 될 때는 rear에서 enqueue 되며, 삭제 될 때는 front에서 dequeue 된다
dequeue가 될 때 front_index가 하나씩 밀리게 된다 이때 그래서 
self.front_index == len(self.items) 부분에서 front_index랑 queue의 길이가 같으면 뒤에 값은 무시하고 queue가 빈다고 말하고 None을 리턴한다

```python
class Queue:
    def__init__(self):
        self.items=[]
        self.front_index=0
    def enqueue(self,val):
        self.items.append(val)
    def dequeue(self):
        if self.front_index == len(self.items)
            print("Q is empty")
            return None
        else:
            x=self.items[front_index]
            self.front_index+=1
            return x
```
