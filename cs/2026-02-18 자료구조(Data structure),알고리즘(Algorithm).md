자료구조: 자료를 담는 구조
    ->자료: data(컴퓨터에 저장)->[저장공간(memory)에 저장+ 읽기,쓰기, 삽입, 삭제, 탐색(연산)]--->구조
 자료구조 예:
  -변수(variable) a=5(이때 5는 a안에 실제 저장되는 것이 아닌, 5가 저장되는 곳의 주소를 저장)
  -배열(array)  
   리스트(list)
 
 


알고리즘: 입력 자료(data)를 통해 문제를 푸는 논리적인 절차. ->유한한 횟수의 연산들을 통해 정답을 출력
인류 최초의 알고리즘: 최대공약수(GCD)


-gcd(8,2)=4
 ->길이 8의 막대를 2등분, 12인 막대를 3등분 한 뒤 길이가 긴 막대를 짧은 막대로 뺀다 그러면 길이가 12인 막대는 4가 된다 그 뒤 위에 방법대로 똑같이 8에서 4를, 4에서 4를 빼면 (4,0)이 된다 이로써 4가 최대공약수가 된다

 이것을 파이썬 코드로 구현 시키면
 ```Python
 
def gcd(a,b):
    while a!=0 and b!=o:
        if a>b:
            a=a-b
        else:
            b=b-a
    return a+b
print(gcd(a,b))
 
 ```
 이다
 여기서 변수 a와b를 각각 2와100으로 저장할때 위에 코드는 50번을 뺀다
 이것은 시간이 너무 오래 걸리므로 나누기로 나머지로 구한다
 이것을 코드로 하면
 ```Python
 def gcd(a,b):
    while a!=0 and b!=o:
        if a>b:
            a=a%b
        else:
            b=b%a
    return a+b
print(gcd(a,b))
 ```
 이다
저 최소공약수의 구하는 방법으로는 
 gcd_sub(반복적으로 빼기),gcd_mod(나누기),gcd_rec(재귀)가 있다
